Cómo crear el token de CloudflareOcultar instrucciones
  1. Cloudflare → Mi perfil → Tokens de API → Crear token → Crear token personalizado.
  2. Permisos: Zona · Zona · Leer (listar zonas al importar) y Zona · DNS · Editar (leer registros y conmutar). Opcional: Zona · Transform Rules · Editar, para que el panel cree la regla de la cabecera secreta hacia el origen.
  3. Recursos de zona: Incluir · Zona específica (una por dominio) o Todas las zonas de una cuenta. No hace falta ningún permiso de cuenta.
  4. Filtrado de IP de cliente: la IP pública del VPS donde corre el controlador (añade la tuya mientras lo pruebas en local).
  5. No uses la Global API Key: da acceso total a la cuenta.

Puedes añadir varias por proveedor: una por cuenta de Cloudflare, o un token por dominio si los limitas a una zona. Cada dominio elige cuál usa en su página de configuración.
